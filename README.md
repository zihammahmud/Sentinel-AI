# Sentinel AI

### An Intelligent Cyber Defense & Attack Simulation Platform

Sentinel AI is a cybersecurity-focused academic software project designed to explore network attack simulation, AI-based search algorithms, threat analysis, and cyber defense decision-making through an interactive web-based environment.

The project demonstrates how classical artificial intelligence concepts can be applied to cybersecurity scenarios in a controlled simulation environment.

> **Project Type:** Academic Project
> **Domain:** Cybersecurity, Artificial Intelligence, Network Simulation
> **Development Approach:** Software-based
> **Status:** Academic prototype / development project

---

## Overview

Modern computer networks face various security threats, including unauthorized access, malicious activity, and potential network vulnerabilities. Understanding these threats and exploring possible defense strategies are important aspects of cybersecurity education.

Sentinel AI provides a simulated environment in which users can explore network structures, observe simulated attack scenarios, and examine how AI algorithms can support network exploration and threat analysis.

The project combines a web-based dashboard with backend processing and algorithmic techniques to demonstrate cybersecurity concepts in an accessible and interactive format.

## Objectives

* Demonstrate fundamental cybersecurity concepts through controlled simulations.
* Explore the application of classical AI algorithms to network exploration and decision-making.
* Represent network structures using graph-based visualization.
* Simulate attack scenarios and display their progression.
* Present threat-related information through a centralized dashboard.
* Provide an educational environment for understanding cyber defense concepts.

## Key Features

The following features describe the intended project capabilities. Retain only the features that are implemented in the current version.

* **Network Visualization:** Represent network nodes and connections in a visual environment.
* **Attack Simulation:** Demonstrate predefined attack scenarios without targeting real systems.
* **Attack Timeline:** Present the sequence of events during a simulation.
* **Threat Analysis:** Display simulated threat information and analysis results.
* **Risk Score:** Present a calculated risk indicator based on the project's implemented logic.
* **AI-Based Network Exploration:** Apply search algorithms to explore network structures or simulated scenarios.
* **AI Recommendations:** Display recommendations generated by the implemented decision logic.
* **Interactive Dashboard:** Provide a centralized interface for exploring simulation results.

## AI Algorithms and Concepts

Sentinel AI explores classical artificial intelligence techniques and their potential applications in cybersecurity simulations.

| Algorithm / Concept                    | Potential application                                        |
| -------------------------------------- | ------------------------------------------------------------ |
| Breadth-First Search (BFS)             | Exploring network nodes level by level                       |
| Depth-First Search (DFS)               | Traversing network structures                                |
| Depth-Limited Search (DLS)             | Exploring a graph within a specified depth                   |
| Iterative Deepening Search (IDS)       | Repeated depth-limited exploration                           |
| A* Search                              | Finding paths using path cost and heuristic estimates        |
| Bayesian Reasoning                     | Representing uncertainty in simulated threat analysis        |
| Constraint Satisfaction Problems (CSP) | Modeling problems with defined constraints                   |
| Alpha-Beta Pruning                     | Optimizing decision-tree exploration in applicable scenarios |

The presence of an algorithm in this table should reflect actual implementation or demonstration in the project.

## Installation and Setup

### Prerequisites

* Python 3.x
* pip
* Git
* A modern web browser

### 1. Clone the repository

```bash
git clone https://github.com/zihammahmud/sentinel_ai.git
```

```bash
cd sentinel_ai
```

Replace the repository URL with your actual GitHub repository URL if it differs.

### 2. Create a virtual environment

```bash
python3 -m venv venv
```

Activate it on Linux or macOS:

```bash
source venv/bin/activate
```

On Windows:

```bash
venv\Scripts\activate
```

### 3. Install dependencies

```bash
pip install -r requirements.txt
```

### 4. Run the application

```bash
python3 app.py
```

Open the local address displayed by Flask in your terminal, commonly:

```text
http://127.0.0.1:5000
```

The exact setup requirements depend on the dependencies and configuration of the current project version.

## Security and Ethical Considerations

Sentinel AI is intended for educational and academic cybersecurity research.

* Attack scenarios are intended to operate within a controlled simulation environment.
* The project is not intended to facilitate unauthorized access to real systems.
* Users should obtain appropriate authorization before conducting any security testing outside the simulation environment.
* Simulated results should not be interpreted as proof that a real network is secure.
* Risk indicators and recommendations should be understood in the context of the implemented algorithms and available data.

**Important:** Sentinel AI is a simulation-oriented project, not a replacement for a professional security assessment, enterprise security monitoring platform, or production-grade incident response system.

## Limitations

The capabilities of Sentinel AI depend on the algorithms, datasets, and simulation logic implemented in the current version.

Potential limitations include:

* Simulated attack behavior may not represent the full complexity of real-world attacks.
* Risk scores may depend on simplified assumptions and predefined rules.
* AI-generated or algorithmic recommendations may require human review.
* The project may not include integrations with real network monitoring or security tools.
* The prototype may not have undergone independent security audits or production-scale testing.
